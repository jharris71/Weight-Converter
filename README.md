# Weight converter 

A simple Python weight converter application built using Tkinter.

This application allows users to convert weights from kilograms into grams, ounces and pounds through a graphical user interface (GUI).

## Features

- Convert kilograms into grams, ounces and pounds.
- Accept whole numbers and decimal inputs.
- Input validation for negative numbers.
- Error handling for empty and non-numeric inputs.
- Interactive GUI built using Tkinter.
- Custom-styled buttons with hover effects.
- Displays conversion results to two decimal places.

## technologies used
-Python - main programming language
-Tkinter - python library used to create graphical user interface
-Visual Code Studio - code editor for development

## Installation
-Python - User must have python installed
-tkinter - User must import tkinter for be able to use the Graphical user interface (GUI)
-Download the project - User must download or clone the GitHub repository

## Usage
open the project – Download the project and open it in Visual Studio Code.
Run the application – Run the Python file to launch the Weight Converter.
Enter a weight – Enter the desired weight in kilograms.
Select a conversion – Click the relevant button to convert the weight into grams, pounds or ounces.
View the result – The converted weight will be displayed in the application.

## conversion formulas
Kilograms to grams: multiply by 1,000.
Kilograms to ounces: multiply by 35.274
Kilograms to pounds: multiply by 2.20462
